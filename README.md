# E-Commerce Website

A full-stack E-Commerce web application built with **React** (frontend) and **FastAPI** (backend).
Users can browse products, add items to their cart, place orders, and leave reviews.
An admin panel lets store owners manage products, categories, and orders.

---

## Features

- **User Authentication** — Register, login, logout with JWT-based auth
- **Product Catalog** — Browse all products with search & filter
- **Shopping Cart** — Add / remove items from cart
- **Order Management** — Place orders, view history, cancel orders
- **Product Reviews** — Leave comments with automatic sentiment analysis (TensorFlow)
- **Product Ratings** — Rate products (averaged automatically)
- **Admin Panel** — Register as an admin, add/edit/delete products, view all orders

## Installation & Setup

### 1 — Backend Setup (FastAPI)

```bash
# Clone the repository
git clone https://github.com/yourusername/e-commerce-website.git
cd e-commerce-website/fastapiApp

# Create and activate a virtual environment
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start the FastAPI server
uvicorn app:app --reload --host 0.0.0.0 --port 8000
```

The backend will be available at **http://localhost:8000**

> **Interactive API docs** (auto-generated by FastAPI): http://localhost:8000/docs

---

### 2 — Frontend Setup (React)

```bash
# Navigate to the frontend directory
cd ../admin

# Install dependencies
npm install

# Start the React development server
npm start
```

The React app will be available at **http://localhost:3000**

## API Endpoints

All endpoints run on `http://localhost:8000`.

### User

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/userRegister` | Register a new user |
| `POST` | `/userLogin` | Login and receive a JWT token |
| `POST` | `/getUserData` | Fetch user profile by auth token |
| `POST` | `/logoutUser` | Invalidate a user's token |
| `PUT` | `/addtoCart` | Add a product to the user's cart |
| `PUT` | `/removefromCart` | Remove a product from the cart |
| `PUT` | `/userOrders` | Place an order |
| `PUT` | `/deleteOrder` | Cancel an order |

### Products

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/getAllProducts` | List all products |
| `POST` | `/addComments` | Add a comment (sentiment-analysed) |
| `POST` | `/addRating` | Rate a product |

### Admin

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/adminRegister` | Register a new admin account |
| `POST` | `/adminLogin` | Admin login |
| `POST` | `/getAdminData` | Fetch admin profile by auth token |
| `POST` | `/addProduct` | Add a new product |

## Environment / Configuration

Open `fastapiApp/app.py` and update:

```python
SECRET_KEY = "your_secret_key"   # Replace with a strong random string
```

For production, use environment variables:

```bash
export SECRET_KEY="super-secret-random-string"
```

---

## Running Both Servers Together

Open two terminal windows:

```bash
# Terminal 1 — Backend
cd fastapiApp
uvicorn app:app --reload --port 8000

# Terminal 2 — Frontend
cd admin
npm start
```

Then open **http://localhost:3000** in your browser.
